🎞️ WORKING WITH ANIMATIONS
═══════════════════════════════════════════════════════════════

METHOD 1: Rendered Animations (Best for motion graphics)

The MarketingExporter renders shockwave animations as PNG sequences:
- 120 frames @ 60fps = 2 second loop
- Full transparency preserved
- Perfect for compositing in After Effects/Motion

To convert PNG sequences to transparent MOV:
   cd MarketingExport/Scripts
   ./convert-to-mov.sh

This creates ProRes 4444 MOV files with alpha channel in:
   MarketingExport/Animations/

Import these MOV files directly into:
- After Effects (File → Import)
- Apple Motion (File → Import)
- Final Cut Pro (drag into timeline)
- DaVinci Resolve (Media Pool → Import)

Benefits:
✓ Perfect transparency/alpha channel
✓ Exact control over animation timing
✓ Easy to composite over other footage
✓ Professional quality (ProRes 4444)


METHOD 2: Screen Recording (For interactive animations)

For environment transitions and AI agent interactions:

1. Use OBS Studio:
   - Canvas: 3840×2160 (4K)
   - FPS: 60
   - Encoder: Apple VT H264 Hardware or ProRes

2. Record specific sequences:
   - Environment transitions
   - AI agent responses
   - Focus mode activation/deactivation

3. Composite with static high-res assets in post


🔧 HOW TO REGENERATE ASSETS
═══════════════════════════════════════════════════════════════

STEP 1: Export Static Images + PNG Sequences

Add to your TOME app (in a debug menu or temporary button):

   import MarketingExporter  // Add Scripts/MarketingExporter.swift to project

   // Export all static environment screenshots
   MarketingExporter.exportAllEnvironments(state: yourTOMEState)

   // Export animated shockwaves as PNG sequences
   MarketingExporter.exportAnimations()

This will create:
- High-res PNGs in Environments/, Components/
- PNG sequences in Animations/PNGSequences/


STEP 2: Convert PNG Sequences to Transparent MOV

   cd MarketingExport/Scripts
   ./convert-to-mov.sh

Requires: ffmpeg (install with: brew install ffmpeg)

This creates ProRes 4444 MOV files with alpha channel in:
   MarketingExport/Animations/


QUICK EXPORT (All in One):

   # In TOME app
   MarketingExporter.exportAllEnvironments(state: state)
   MarketingExporter.exportAnimations()

   # In Terminal
   cd MarketingExport/Scripts && ./convert-to-mov.sh

Done! All assets ready for video production.
